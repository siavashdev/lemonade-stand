# v0.13.0

_Release date: 2026-11-14_

See what the Lemonade server is doing at a glance, without relying on fan noise or the log stream, and let the agent drive a real browser with the new Playwright tool in the Pantry.

## Added
- **Playwright Browser** in the Pantry: lets the agent open pages, click, type, read page snapshots, and take screenshots. The server is bundled with the app, so no Node install is needed, but the browser itself is not: it drives Chrome, Edge, or Playwright's own Chromium that is already on your machine.
- **Pantry settings:** a tool can now offer settings on its card, applied with **Apply settings** and restarting the tool for you. Playwright Browser uses this for **Browser** (Google Chrome, Microsoft Edge, or Playwright Chromium; Edge is the default on Windows, Chrome elsewhere), **Private session** (on by default: the browser profile lives in memory only, like an incognito window, so cookies and sign-ins don't carry over) and **Run headless** (off by default, so a visible window opens and you can watch the agent work).
- **Monitoring pill** in the status bar: a dot that pulses green while the model is working, the live speed in tokens per second with a small graph, and CPU. Click it (or **Monitoring** in the hamburger menu) for live graphs of the Lemonade server's resource usage and inference speed.
- **Detachable Monitoring window:** pop it out of the overlay with its button, or drag its title bar toward the edge of the window and release when the banner says so, and it opens as its own window where you dropped it. Place it beside, or outside, the main window so you can chat and watch the graphs at the same time. It follows the theme, keeps its graphs when popped out, and closes with the app.
- **Inference:** a Generating/Idle indicator with the number of active requests, the live generation speed in tokens per second with a three-minute graph, the last request's speed and time to first token, prompt and cached token counts, and totals.
- **System:** CPU, memory, GPU (with its name), GPU memory, and NPU graphs. A card shows "n/a" when the server or your hardware doesn't report that number.
- **Recent requests:** a table of each request that finishes, with its tokens per second, time to first token, and token counts.
- Monitoring reads the server's `/stats` and `/system-stats` endpoints about once a second while the app window is visible, and stops while it is hidden or minimized.

## Changed
- If a tool call is waiting for your approval while the Monitoring overlay is open, it says so, since the overlay covers the chat. The detached window never covers the chat.

## Fixed
- The Windows taskbar showed the Electron icon instead of the lemon icon. Windows picks the taskbar icon from any Start Menu shortcut that shares the app's ID, and a leftover shortcut to a development `electron.exe` (created when running from source) was taking priority over the installed app. Development runs now use their own app ID so they can't affect the installed app, and every window sets its icon explicitly. If you still see the Electron icon after updating, delete any stray `Electron` shortcut from your Start Menu Programs folder (`%APPDATA%\Microsoft\Windows\Start Menu\Programs`) and restart Windows Explorer.

- Long conversations could fail partway through a run with `Jinja Exception: System message must be at the beginning.` Compacting a conversation adds a summary and the current plan as extra system messages, and some models' chat templates (such as Qwen3) accept only one, at the start. All system messages are now merged into a single leading message before each request.

## Known issues
- Playwright Browser doesn't install a browser for you. If the chosen one isn't found, its tools report an error naming what to install; Playwright Chromium needs a one-time `npx @playwright/mcp install-browser chrome-for-testing`.
- Playwright Browser acts with the app's privileges and can reach any site you can, so review its approval cards. Its private session keeps sign-ins from carrying over between sessions, but anything you sign in to during one stays reachable by the agent until the tool restarts.
- Monitoring graphs cover the last three minutes and are kept only while the app window is visible, so they start empty after the app has been hidden or minimized for a few seconds.
- Omni models send their reply all at once, so there is no live speed while they work: the live reading appears for a few seconds when each model call finishes, and the speed stays under Last request. When the server's log has no timing for a request (other backends), the figures are estimates marked **~** (about four characters per token, over the whole request including tool time).
- Monitoring needs a Lemonade server that provides `/stats` and `/system-stats`; on an older server those cards show "n/a".
- GPU and NPU numbers depend on your operating system and drivers, and are not available on every machine.
- Requests that finish within the same second show as one row in Recent requests.
