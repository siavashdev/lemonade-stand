# v0.12.0

_Release date: 2026-11-13_

Compatibility with Lemonade Server v2026.46.2, plus in-app diagnostics for both the server and Lemonade Stand.

## Added
- **Separate log viewers** under the hamburger menu for the Lemonade server and Lemonade Stand itself.
- Search, severity filters, live follow, copy, clear, connection status, and access to the optional on-disk app log.

## Changed
- Updated the documented Docker setup to persist all current Lemonade server data and configuration volumes.
- Expanded model classification for the latest server labels, including transcription, image, audio, embedding, reranking, and classification models.
- Updated Electron, OpenAI, MCP, sanitization, and build dependencies to patched releases; the release audit has no high or critical findings.

## Fixed
- Omni collections now preflight their component downloads and explain missing components instead of returning a cryptic chat response.
- Omni chat failures delivered as normal assistant text are now surfaced as real, actionable errors.
- Omni collections load their LLM component with the requested context size instead of silently running at 4096 tokens.
- Fully installed Omni collections remain available when the server incorrectly flips the collection's own `downloaded` flag to false.
- Dictation only selects an already-downloaded speech-to-text model, preventing an unexpected model download and apparent hang.
- A slow startup model load can no longer override a newer model selected by the user.
- Server log streams stop cleanly when the window reloads or exits, and clearing a viewer also discards queued lines.

## Known issues
- Audio data URLs returned directly inside an Omni assistant reply are not yet extracted into a playable audio artifact.
